# v5 batch 7 contrast audit

Generated by `npm run screenshots:batch7` from the rendered page; `npm run test:ui` (test/ui/a11y.test.js) fails on the same checks.
Each ratio is the lowest measured at 1920x1080, 390x844 and 360x640 in these states: betting, win, no-win, double-run, double-hit, gamble, paytable, gamble-won, gamble-lost, running, no-bets, over-balance, help, settings, results, refill, start. Fades are composited over what is behind them.

- Text needs 4.5:1 at every size. Large text gets no 3:1 allowance.
- Disabled controls are exempt, as in WCAG 1.4.3 (192 text measurements skipped: disabled secondary buttons, chips, bar icons and switches).
- Non-text means borders, fills and rings that carry a state or identify a control. Plain dividers and the hairline around a control that is already identified by its text are decorative and not listed.
