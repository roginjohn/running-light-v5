# Running Light (working title)

Browser version of the Philippine perya "Running Light" bulb-track game, **Redesign v2 ("Perya After Dark")**.
**Play credits only. No real money value.** No payments, accounts, backend, analytics or network requests at runtime.

## Supported screens (v2 scope)

| Breakpoint | Match | Layout |
|---|---|---|
| desktop-xl | width ≥ 1600 (ref 1920×1080) | header 64 · left rail 440 · stage (16×11 track, 76×72 tiles) · utility bar |
| desktop | 1200–1599 (ref 1280×720) | header 52 · rail 356 · stage (48×47 tiles) |
| tablet-landscape | 900–1199 (ref 1024×768) | header 52 · compact rail 264 · stage (40×50 tall tiles) |
| tablet-portrait | 600–899 and portrait (ref 768×1024) | header 56 · stage on top · dock with 2 panels |
| phone | < 600 and portrait (ref 390×844, 360×640) | bar on top · 11×16 ring (12×15 at 700 px tall or less) · compact dock |

Below **320 px wide or 480 px tall** the "Rotate / enlarge" screen is shown. Landscape windows narrower than 900 px
use the tablet-landscape layout, scaled to fit.

## Stack

- Plain JavaScript ES modules (no framework). v2 renders with **DOM + CSS** (absolute positions computed from the
  layout tokens in `src/ui/layout.js`); the 50 tiles are persistent `<button>`s and only changed tiles update per frame.
- **Vite 5** for the dev server and the static `dist/` bundle (fonts and SVG assets bundled, relative paths, offline).
- **node:test** for unit tests and the simulation driver; **puppeteer-core** + installed Google Chrome for UI tests.
- Fonts: **Bungee** (display) and **Plus Jakarta Sans** 500–800 (UI, tabular numbers), SIL OFL 1.1, from
  `@fontsource/*`, bundled as WOFF2 in `src/assets/fonts/`; licences in `public/fonts/`. (The v1 Lobster/Carter One/
  Nunito packages are still listed as dev dependencies but are no longer bundled.)
- Design tokens: `src/data/design-tokens-v2.json` (copy of the approved file) → `src/styles/tokens.css`, generated by
  `scripts/gen-tokens.js` (runs before `dev`/`build`; it fails if any WCAG contrast pair fails).
- Audio: procedural Web Audio, unchanged from v1 (see `AUDIO.md`).

## Install, run, build

```bash
cd game
npm install                 # dev dependencies only
npm run dev                 # http://localhost:5173
npm run build               # -> dist/ (static, offline)
npm run preview             # serve dist/ on http://localhost:4173
```

## Tests

```bash
npm test                    # unit tests: engine, math, recovery, key map, v1 light path, v2 light plan, v2 tokens
npm run build && npm run test:ui     # v2 browser tests (4 breakpoints, touch, recovery, console/network checks)
npm run screenshots:v3      # v3 states + side-by-side with docs/design-v3 mockups -> docs/design-v3/batch-7/
npm run perf:trace          # Chrome trace of one round, desktop and 4x CPU: long tasks, layouts, credits count-up
npm run sim                 # seeded simulation (default 5,000,000 rounds per strategy)
node scripts/simulate.js --rounds 10000000 --rounds-b 40000000 --seed 20261023 --out test-results/v2/simulation
node scripts/run-all.js     # tokens + build + unit + UI + screenshots; outputs saved in test-results/v3/
```

Set `CHROME=/path/to/chrome` if Chrome is not at `/usr/bin/google-chrome`.

## Behaviour notes (v2 approved defaults)

- Start screen after loading (flag `START_SCREEN` in `src/main.js`, default ON): PLAY is the first gesture and
  unlocks audio. Turbo is a disabled placeholder. Multipliers display as capitals ("24X", "★1920X").
- Light run 4–6 s at ≈18 squares/s cruise, 1–2 laps; Double Run second light 2–3 s, under one lap.
- Gamble loss shows a "No match" view in the gamble dialog and continues by itself after 3 s (or Enter / the button).
- Ghost (last-round) badges hide as soon as one live bet is placed and return after the next collect.
- A corrupt or invalid settings key is reset to the defaults (toast + notice in Settings); a corrupt balance/round
  key still goes to the ERROR dialog. Info and Settings are locked from START until the round is settled.
- RNG: `crypto.getRandomValues` with rejection sampling. Outcomes are drawn and stored **before** any animation.
  Test mode (seeded RNG, forced outcomes) is enabled only when a harness defines `window.__RL_TEST__` before load.
- Persistence keys: `rl.v1.balance`, `rl.v1.settings`, `rl.v1.lastBets`, `rl.v1.round`, `rl.v1.history`.
